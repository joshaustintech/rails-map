# Issue tracker: Local Markdown

Specs and issues live under `.scratch/`.

- One feature per directory: `.scratch/<feature>/`.
- Keep the feature spec in `spec.md`.
- Store each issue in `issues/NN-<slug>.md`, numbered in dependency order.
- Record blockers in each issue's `Blocked by:` field.
- Record triage state in each issue's `Status:` field.
- Keep actionable issues `ready-for-agent`; dependency links describe technical sequencing.
- Append discussion to `## Comments` in the relevant issue.

The current feature tracker is `.scratch/rails-map-completion/`.
